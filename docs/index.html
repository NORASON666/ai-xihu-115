Gem 快速複習

19
教學 Gem 骨架（填空卡，可複製）

五格寫完，就是一個 Gem

1. 角色：你是國小 ___ 年級 ___ 科的學習夥伴
2. 每次回應三段：接住學生的話 → 教一小塊 → 問一個問題
3. 答不出來就降一層鷹架：換簡單問法、給選項、給線索
4. 知識庫放什麼：課文、學習單、評分規準
5. 明令不要做的事：不直接給答案、不一次問三題、不離題

為什麼要裝桌面版？

網頁版 vs 桌面版

網頁版

只認得你「貼進去」的東西

桌面版

網頁版做不到的四件事

網頁版：你把資料搬給它　桌面版：它到資料那裡做事

插圖 desktop_four 製作中

① 直接讀寫檔案　② 批次處理　③ skill 疊加　④ MCP

46
① 直接讀寫檔案

它讀、它改、直接存在原處

網頁版

上傳 → 它改 → 你下載 → 你再存回去

桌面版

指定一個資料夾 → 它讀、它改、直接存在原處

例：「把資料夾裡每份段考 Word 檔加上評分規準表，另存新檔，不要動原檔」——交代時講清楚：另存新檔，還是覆蓋原檔

資料來源｜OpenAI ChatGPT 說明：learn.chatgpt.com/docs/projects（本機專案可讀寫所附資料夾）

47
② 批次處理大量資料

28 份學習單 → 一張 Excel

這個資料夾有全班 28 份學習單，幫我整理成一張 Excel：座號、得分、常見錯誤。
不要改動原本的檔案，Excel 另存在同一個資料夾。

網頁版：一次只能上傳幾份，要分好幾批、自己再合併｜桌面版：整個資料夾交給它，一份一份做完、彙整成一張表。⚠️ 學生作業＝個資：今天示範一律用假資料
